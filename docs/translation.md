# 翻訳ガイド

Windows版とWeb版は同じ[言語データ](../FEFWRNGSolver.Web/wwwroot/languages/)を使います。既存の訳を直すときは、該当する言語フォルダーのJSONを編集します。

## 新しい言語を追加する

1. 言語データの `en/` または `jp/` をコピーし、新しい言語コードと同じ名前のフォルダーを作ります。フランス語なら `fr/` です。
2. コピーした4つのJSONファイルで、キーのIDを保ったまま値の文字列を翻訳します。ファイルはUTF-8で保存します。
3. [languages.json](../FEFWRNGSolver.Web/wwwroot/languages/languages.json) の配列に新しい言語の項目を追加します。フランス語の場合は次のようになります。

```json
{ "code": "fr", "displayName": "Français", "matchCodes": ["fr"] }
```

`displayName` は「設定」→「言語」に表示する名前です。`matchCodes` には初回起動時に照合する言語タグを指定します。たとえば `fr-CA` は `fr-CA`、`fr` の順で照合します。日本語は `ja-JP` が `ja` に一致し、`jp/` の辞書が選ばれます。

## 翻訳するファイル

| ファイル | 翻訳する内容 |
| --- | --- |
| `system.json` | メニュー、能力名、動物名、メッセージなど（`SYS_…`） |
| `character.json` | ユニット名（例 `PID_カイ`） |
| `job.json` | 兵種名（例 `JID_闘士`） |
| `skill.json` | スキル名（例 `SID_戦車兵の道`） |

文中の `{0}` や `{1:N0}` には実行時に値が入ります。これらはそのまま残し、位置は翻訳先の語順に合わせてください。辞書や項目が欠けている場合は、IDごとに選択言語、英語、日本語の順に訳を探し、どの辞書にも訳がなければIDを表示します。

## 表示を確認して送る

配布物で試す場合は、更新した辞書と `languages.json` を、Windows版ならexeの隣、Web版なら配信先の直下にある `languages/` にコピーします。アプリを再起動するかWebページを再読み込みし、「設定」→「言語」で追加した言語を選んで表示を確認してください。

初回はWindowsの表示言語またはブラウザの優先言語に合わせて起動し、一致する言語がない場合は英語を使います。手動で選択した言語は次回の起動にも引き継がれます。

確認が済んだら、リポジトリの言語データへの変更をプルリクエストで送ってください。
